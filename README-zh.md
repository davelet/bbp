# BBP公式 π 计算器

本项目是一个使用 Rust 实现的 Bailey-Borwein-Plouffe (BBP) 公式计算 π 的程序。它最显著的特点是可以直接计算 π 的第 *n* 个十六进制数字，而无需计算前面的所有数字。

## BBP 公式

BBP 公式于 1995 年由 Simon Plouffe 与 David H. Bailey 和 Peter Borwein 合作发现。该公式提供了一种在 16 进制下计算 π 的方法。

公式为：
$$
\pi = \sum_{k=0}^{\infty} \frac{1}{16^k} \left( \frac{4}{8k+1} - \frac{2}{8k+4} - \frac{1}{8k+5} - \frac{1}{8k+6} \right)
$$

这种流出算法允许直接提取 π 的单个十六进制数字。

## 数学逻辑：学生指南

假设你想找到 π 的第 100 个数字。通常，你必须计算出前 99 个数字。而 BBP 公式就像一个魔术，能让你直接得到 π 的第 100 个十六进制数字，而不需要先计算出前面的数字。

### 核心思想：小数点的移位

例如，π 在十六进制下的写法为 `3.243F6A...`。

- 小数点后的第一位是 `2`。
- 第二位是 `4`。
- 第三位是 `3`。

假设我们需要找到第 **2** 位（即 `4`）。如果将 π 乘以 16（在十六进制中为“10”），小数点就会右移一位：
```
π * 16^1 = 32.43F6A...
```
现在，我们需要的数字 `4` 就出现在新的小数点后首位。

如果需要找到第 **4** 位（`F`），则乘以 `16^3`：
```
π * 16^3 = 3243.F6A...
```
此时，目标数字 `F` 就变为了小数点后的第一位。

因此，主要思想是：**要找出 π 的第 *n* 个十六进制数字，可以计算 `16^(n-1) * π`，然后观察小数点后的首位数字。**

### 问题：无法直接使用 π

表面上看起来很简单，但问题在于：为了计算 `16^(n-1) * π`，你需要知道 π 的值，而 π 是一个无限不循环的小数，计算机无法存储所有其数字。

这时，BBP 公式发挥作用。它为我们提供了一种方法来计算 `16^(n-1) * π` 的**小数部分**，而无需得知 π 的全貌。

### 解决方案：分解 BBP 公式

BBP 公式实际上是很多小分数之和。当我们将其乘以 `16^(n-1)`，会得到一个新的巨大的求和表达式：
$$
16^{n-1}\pi = \sum_{k=0}^{\infty} \left( \frac{4\cdot 16^{n-1-k}}{8k+1} - \frac{2\cdot 16^{n-1-k}}{8k+4} - \frac{1\cdot 16^{n-1-k}}{8k+5} - \frac{1\cdot 16^{n-1-k}}{8k+6} \right)
$$

我们只关注这个求和的**小数部分**。关键在于可以将该求和分为两部分：

1.  **前头部分（Head，k 从 0 到 n-1）**：
    这些项中 `16^(n-1-k)` 为正幂，会产生较大的整数。但由于我们只关心小数部分，可通过模运算（模指数运算）计算出每项对小数部分的贡献。

2.  **尾部部分（Tail，k 从 n 到无穷）**：
    这些项中的 `16^(n-1-k)` 为负幂，产生极小的数（例如 `1/16`, `1/256`）。可以使用标准浮点数（`f64`）来求和，直到这些项变得足够小，不再影响结果为止。

将前头部分的小数贡献与尾部全部求和得到的值相加，就得到了 `16^(n-1) * π` 的小数部分。

### 快速预备知识

为了更好地理解上述内容，你需要具备以下基础知识：

- 如何表示十六进制数字，
- 无限级数和求和分解的基本概念，
- 模运算（即取余运算）的基础（例如模指数运算）。

如果这些内容不够熟悉，下文提供了一段简短的入门说明。

### 简短的模运算入门

模运算关注的是余数。例如，`a mod m` 表示 a 除以 m 后的余数。一条有用的性质是：

`16^e mod m` 即使在 e 很大时也能高效计算，这就是模指数运算。举例：

- `16^3 = 4096`，而 `4096 mod 7 = 4096 - 7*585 = 1`，因此 `16^3 mod 7 = 1`。

这对于计算前头部分的项的小数贡献非常重要，因为它避免了直接计算非常大的整数。

### 数值示例（n = 2）

以下展示如何求出 π 的第 2 个十六进制数字（在 `3.243F6A...` 中已知为 `4`）。对于 `n = 2`，我们需要计算 `16^(n-1) = 16`。

1. 写出乘以 `16^(n-1)` 后的 BBP 求和，展示四个分数项：
   $$
   16\pi = \sum_{k=0}^{\infty} \left( \frac{4\cdot 16^{1-k}}{8k+1} - \frac{2\cdot 16^{1-k}}{8k+4} - \frac{1\cdot 16^{1-k}}{8k+5} - \frac{1\cdot 16^{1-k}}{8k+6} \right)
   $$
2. 将求和分为前头部分（k = 0 到 1）和尾部部分（k ≥ 2）：
   - 前头项：这些产生正幂（16^1 和 16^0）的项，通过模运算来计算它们的小数贡献。
   - 尾部项：这些产生负幂（如 16^{-1}, 16^{-2}, ...）的项，用浮点数求和近似即可。
3. 将前头部分和尾部部分相加，得到 `16π` 的小数部分，再将该部分乘以 16，取整数部分，即可得到目标数字。

实际计算将得到一个小数，其首个十六进制数字为 `4`，与预期一致。

### 尾部精度说明

如前所述，对于尾部项，我们通常使用 `f64` 类型进行计算，因为尾部项迅速衰减，对于中等范围的 n 足以保证精度。如果需要计算非常高精度的数字，请考虑使用任意精度算术（本项目中已在十六进制转十进制时使用 `bigdecimal` 库）。

## 代码实现结构

项目分为三个主要模块：

### `src/main.rs`

这是程序入口，主要完成以下任务：

1. 调用 `bbp::get_digits()` 计算 π 的一系列十六进制数字；
2. 输出这些十六进制数字；
3. 使用 `decimal::hex_pi_to_decimal()` 将十六进制数字转换为高精度的十进制表示；
4. 演示单独计算某一位（例如第 10 位和第 50 位）的功能；
5. 提供一个验证部分，将结果与已知的 π 值进行比对。

### `src/bbp/mod.rs`

该模块包含 BBP 公式的核心逻辑：

- `get_digit(n)`：计算 π 的第 n 个十六进制数字（n 从 1 开始）。
- `series_sum(n, j)`：计算 BBP 公式中给定 n 和偏移量 j 的级数和。
- `mod_pow(base, exp, modulus)`：高效实现模指数运算，避免直接计算非常大的数字。

### `src/decimal/mod.rs`

该模块负责将计算出的十六进制数字转换为标准的十进制表示：

- `hex_pi_to_decimal(hex_digits, precision)`：将十六进制字符串转换成十进制字符串。它使用 `bigdecimal` 库进行任意精度运算，确保转换精度。

## 使用说明

### 环境要求

你需要安装 Rust 工具链。请访问 [rustup.rs](https://rustup.rs/) 获取安装指南。

### 运行项目

在项目目录下使用 Cargo 运行：

```bash
cargo run
```

程序会输出：

1. π 的前 500 个十六进制数字；
2. 这些数字转换成的十进制表示；
3. 单独计算（例如第 10 位和第 50 位）的十六进制数字；
4. 与已知 π 值对比的验证部分。

### 构建项目

若要构建优化后的可执行文件，请运行：

```bash
cargo build --release
```

编译后的二进制文件位于 `target/release/bbp`。

## 依赖

- `bigdecimal`：用于高精度十进制运算，将十六进制转换为十进制时保证精度。
