# Калькулятор π по Формуле BBP

Этот проект представляет собой реализацию формулы Бэйли-Борвейна-Плуфф (BBP) для вычисления цифр числа π на языке Rust. Его главная особенность заключается в возможности вычисления n‑й шестнадцатеричной цифры числа π без необходимости вычислять все предыдущие цифры.

## Формула BBP

Формулу BBP открыли в 1995 году Саймон Плуфф, Дэвид Бейли и Питер Борвейн. Она позволяет вычислять π в шестнадцатеричной системе счисления.

Формула выглядит следующим образом:
![Формула BBP](https://latex.codecogs.com/png.latex?\pi%20=%20\sum_{k=0}^{\infty}%20\frac{1}{16^k}%20\left(%20\frac{4}{8k+1}%20-%20\frac{2}{8k+4}%20-%20\frac{1}{8k+5}%20-%20\frac{1}{8k+6}%20\right))

Этот алгоритм позволяет извлекать отдельные шестнадцатеричные цифры числа π непосредственно.

## Математическая Логика: Руководство для студентов

Представьте, что вы хотите узнать 100-ю цифру числа π. Обычно для этого нужно вычислить первые 99 цифр. Формула BBP позволяет найти 100-ю цифру в шестнадцатеричном представлении π, не вычисляя все предыдущие.

### Основная Идея: Сдвиг Десятичной Точки

Например, π в шестнадцатеричной системе выглядит так: `3.243F6A...`.

- Первая цифра после точки — `2`.
- Вторая — `4`.
- Третья — `3`.

Чтобы получить вторую цифру (`4`), умножим π на 16 (в шестнадцатеричной системе это `10`), что сдвинет точку на один разряд вправо:
```
π * 16^1 = 32.43F6A...
```

Цифра `4` станет первой после новой точки.

### Проблема: Невозможно Использовать π Прямо

Чтобы вычислить `16^(n-1) * π`, надо знать само число π, которое бесконечно и не может быть полностью сохранено в памяти компьютера.

Формула BBP позволяет вычислить только дробную часть выражения `16^(n-1) * π`, обходя необходимость хранения всех цифр π.

### Решение: Разбиение Формулы BBP

Формула BBP представляет собой бесконечную сумму малых дробей. При умножении на `16^(n-1)` сумма записывается так:
![Умноженная формула BBP](https://latex.codecogs.com/png.latex?16^{n-1}\pi%20=%20\sum_{k=0}^{\infty}%20\left(%20\frac{4\cdot%2016^{n-1-k}}{8k+1}%20-%20\frac{2\cdot%2016^{n-1-k}}{8k+4}%20-%20\frac{1\cdot%2016^{n-1-k}}{8k+5}%20-%20\frac{1\cdot%2016^{n-1-k}}{8k+6}%20\right))

Дробная часть этой суммы вычисляется с помощью двух слагаемых:

1. **Head (от k = 0 до n‑1):** Эти слагаемые дают большое число, но их дробная часть вычисляется с помощью модульной арифметики.
2. **Tail (от k = n до бесконечности):** Эти слагаемые очень малы и их можно суммировать с использованием чисел с плавающей точкой (f64).

Сумма этих двух частей даёт дробную составляющую выражения `16^(n-1) * π`.

## Структура Кода

Проект разделён на несколько модулей:

### `src/main.rs`

Точка входа в программу, которая:
- Вызывает функцию `bbp::get_digits()` для вычисления шестнадцатеричных цифр π;
- Преобразует их в десятичный вид с помощью `decimal::hex_pi_to_decimal()`;
- Выводит результат и выполняет проверку корректности.

### `src/bbp/mod.rs`

Содержит основную логику вычисления по формуле BBP:
- Функции: `get_digit(n)`, `series_sum(n, j)` и `mod_pow()`.

### `src/decimal/mod.rs`

Преобразует шестнадцатеричные цифры в десятичное представление, используя crate `bigdecimal` для обеспечения высокой точности вычислений.

## Использование

### Требования

Необходим установленный Rust (см. [rustup.rs](https://rustup.rs/)).

### Запуск

Выполните:
```bash
cargo run
```

Программа выведет:
- Первые 500 шестнадцатеричных цифр π;
- Их десятичное представление;
- Отдельные примеры (например, 10-й и 50-й цифры);
- Сверку с известным значением π.

### Сборка

Для сборки оптимизированного исполняемого файла выполните:
```bash
cargo build --release
```
Исполняемый файл будет находиться в `target/release/bbp`.

## Зависимости

- `bigdecimal`: Используется для обеспечения вычислений с произвольной точностью при преобразовании из шестнадцатеричного в десятичное представление.
