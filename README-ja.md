# BBP 公式による π 計算機

このプロジェクトは、Rust で実装された Bailey-Borwein-Plouffe (BBP) 公式を用いて π の桁を計算するプログラムです。本プロジェクトの最も特徴的な点は、前の桁を計算することなく、直接 π の n 番目の16進数の桁を求めることができる点にあります。

## BBP 公式

BBP 公式は、1995年に Simon Plouffe、David H. Bailey、Peter Borwein によって発見されました。この公式は、16進数表記で π を計算する方法を提供します。

公式は以下の通りです:

![BBP 公式](https://latex.codecogs.com/png.latex?\pi%20=%20\sum_{k=0}^{\infty}%20\frac{1}{16^k}%20\left(%20\frac{4}{8k+1}%20-%20\frac{2}{8k+4}%20-%20\frac{1}{8k+5}%20-%20\frac{1}{8k+6}%20\right))

このスピゴットアルゴリズムにより、π の16進数の桁を直接抽出することができます。

## 数学的な論理: 学生向けガイド

例えば、π の100番目の桁を求めたいとしましょう。通常は、前の99桁を計算する必要がありますが、BBP 公式を使うと、前の桁を計算することなく、直接100番目の16進数の桁を取得できます。

### 基本的なアイデア: 小数点の移動

例えば、π は16進数では `3.243F6A...` と表されます。

- 小数点以下最初の桁は `2`。
- 2番目は `4`。
- 3番目は `3`。

もし2番目の桁（`4`）を求めるなら、π に16（16進数では "10"）を掛けると小数点が1桁右へ移動します:
```
π * 16^1 = 32.43F6A...
```

こうして、求めたい桁 `4` が新しい小数部分の最初の桁となります。

### 問題点: π を直接使えない

`16^(n-1) * π` を計算するには π の値が必要ですが、π は無限に続く数なのでコンピュータ上で全桁を扱えません。

そこで、BBP 公式は `16^(n-1) * π` の**小数部分**だけを計算する方法を提供します。

### 解決策: BBP 公式の分割

BBP 公式は多くの小さな分数の和として表されます。`16^(n-1)` を掛けると、以下のような形になります:

![乗算済みBBP公式](https://latex.codecogs.com/png.latex?16^{n-1}\pi%20=%20\sum_{k=0}^{\infty}%20\left(%20\frac{4\cdot%2016^{n-1-k}}{8k+1}%20-%20\frac{2\cdot%2016^{n-1-k}}{8k+4}%20-%20\frac{1\cdot%2016^{n-1-k}}{8k+5}%20-%20\frac{1\cdot%2016^{n-1-k}}{8k+6}%20\right))

この和の小数部分を求めるために、計算を以下の2つに分けます:

1. **ヘッド (Head)**: k = 0 から n-1 までの項。これらは正の指数を持ち、大きな数になりますが、各項の小数部分はモジュラー演算によって効率的に計算できます。
2. **テイル (Tail)**: k = n から無限大までの項。これらは負の指数を持ち、非常に小さな値となり、f64 などの浮動小数点数で十分に計算が可能です。

これら2つの部分の小数値を足し合わせることで、`16^(n-1) * π` の小数部分が得られます。

## コードの構造

このプロジェクトは主に以下の3つのモジュールに分かれています:

### `src/main.rs`

- プログラムのエントリーポイントです。
- `bbp::get_digits()` を呼び出して 16 進数の桁を計算し、
- `decimal::hex_pi_to_decimal()` を用いて高精度の10進数に変換します。

### `src/bbp/mod.rs`

BBP 公式の主要な計算ロジックを含みます:
- 関数: `get_digit(n)`、`series_sum(n, j)`、`mod_pow()`。

### `src/decimal/mod.rs`

計算された 16 進数の桁を、`bigdecimal` クレートを使用して 10 進数に変換する機能を持っています。

## 使用方法

### 前提条件

Rust ツールチェーンをインストールしてください（[rustup.rs](https://rustup.rs/) を参照）。

### 実行

プロジェクトディレクトリで以下を実行します:
```bash
cargo run
```
プログラムは以下を出力します:
- π の最初の500桁の 16 進数表現
- その 10 進数変換結果
- 各桁の個別例（例: 10 番目と 50 番目の桁）
- 既知の π の値との検証

### ビルド

最適化された実行ファイルをビルドするには:
```bash
cargo build --release
```
実行ファイルは `target/release/bbp` に配置されます。

## 依存関係

- `bigdecimal`: 16 進数から 10 進数への変換の際に、任意精度計算のために使用されます。
